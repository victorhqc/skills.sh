# Word choice

Selected words that STE does not approve, with possible replacements. Check
each meaning and part of speech in the ASD-STE100 Issue 9 dictionary. Rows
marked (house) are local guidance. This list does not prove STE compliance.
Preserve the source meaning when a replacement does not fit.

## Recurring errors

STE lists these as the errors that writers make most. Learn these first.

| Do not write | Write |
| --- | --- |
| ensure | make sure that |
| check (v), verify, ascertain | make sure that, examine, do a check of |
| test (v) | do a test of, run the tests |
| follow (instructions) | obey |
| perform, execute (a step) | do |
| need, require, required | necessary (`X is necessary`), or `must` for a requirement |
| have to | must, or the imperative |
| may | `can` only when it means ability or permission; see Obligation |
| should | identify its meaning; see Obligation |
| shall (requirement) | must |
| since (meaning because) | because |
| however | but |
| therefore | thus, as a result |
| further | more |
| avoid | prevent |
| any | a different construction: `if you find cracks`, not `if you find any cracks` |
| both | the two |
| main | primary |
| now | at this time, or give the time |
| repeat | do ... again |
| damage (v) | cause damage to |

`follow` stays only in its one meaning, "come after": `The retry follows the
first attempt.`

## Verbs

| Do not write | Write |
| --- | --- |
| utilize, leverage (house) | use |
| guarantee (house) | state the actual mechanism and result; do not add certainty |
| enable, allow, permit | let. Keep `enable` and `disable` as technical verbs for a flag or a feature |
| facilitate, assist | help |
| initiate, commence, kick off, spin up | start |
| terminate, end (v) | stop |
| provide | give |
| obtain, acquire, reach | get |
| retain | keep |
| attempt | try |
| indicate | show |
| determine | find |
| detect (in general text) | find |
| modify, alter | change |
| construct, build (a thing) | assemble, make. `build` stays as a technical noun and verb for a software build |
| comprise, constitute | have, be |
| happen, transpire | occur |
| implement | do, make, write |
| surface (a problem) | show, tell |
| handle (an event) | process |
| consider | think |
| decide | select |
| analyze | do an analysis of |
| improve | make better |
| support (v) | hold, or `can`: `the API can do X` |
| fail to | does not; use `did not` for a past event |
| fix (a bug) | correct |
| ask someone to do something | tell someone to do it only if the source gives an instruction; otherwise keep it as a request |
| call (contact someone) | write to, telephone, or tell, as applicable |
| call (invoke code) | use as a technical verb only if the subject field approves it |
| reach out to | contact or write to, as applicable |
| list (v), note (v) | record |
| raise (a value) | increase |
| iterate on (house) | change |

## Phrasal verbs

STE rule 9.3 forbids phrasal verbs. Write one verb with one meaning.

| Do not write | Write |
| --- | --- |
| look into, go through | examine |
| find out, figure out | find |
| carry out | do |
| clean up | remove |
| set up | configure, install |
| turn on, turn off | enable, disable, or set to ON, set to OFF |
| back up | make a backup of |
| roll back | do a rollback of, restore the previous version |
| shut down | stop |
| come up with | find, write |
| point out | show, tell |
| give off, send out | release, send |

## Quantity and size

| Do not write | Write |
| --- | --- |
| about, around, roughly (a quantity) | approximately. In STE, `about` means only "concerned with" |
| a number of, several | some, or the number |
| numerous | many, or the number |
| the majority of | most |
| enough, a sufficient amount of | sufficient |
| additional | more |
| few, a small number of | a small number, or the number |
| multiple | more than one, or the number |
| twice | 2 times |
| above, below (a limit) | more than, less than. `above` and `below` are for positions only |
| significant, substantial | important, or give the number |
| minimal, negligible (house) | give the number |

`significant` has a statistical meaning. Never use it to mean "large".

## Vague words to replace with a fact (house)

These words can hide useful detail. Seek evidence for a number, name, or date.
Do not invent one. STE rule 4.1 asks for accurate, specific text.

| Vague | Ask yourself |
| --- | --- |
| recently, soon, currently | which date? |
| some users, a few records | how many? |
| slow, fast | how long? |
| large, small, huge | what size? |
| often, sometimes, rarely | how many times, in what period? |
| might, could, possibly | what is the source of uncertainty? Keep it if the degree of certainty matters. |
| various, certain, appropriate | which ones? STE: `different`, `applicable` |
| robust, clean, proper, better | better in what measurable way? |
| basically, essentially, simply | delete the word |
| obviously, clearly, of course | delete the word |
| just, actually, really | delete the word, or write `only` |

## Obligation

| Do not write | Write |
| --- | --- |
| shall, needs to, is to, has to (requirement) | must |
| should (requirement) | must |
| should (advice) | name the source and use `recommend that ...` |
| should (prediction) | state the expected result only if the source supports it; otherwise flag the uncertainty |
| may (ability or permission) | can |
| may, might, could (uncertain event) | preserve the degree of uncertainty; flag it if no faithful STE form is available |
| should not (prohibition) | must not, do not |
| should not (advice) | name the source and use `recommend that ... not ...` |
| it is recommended that | name the source and use `recommend that ...` |
| it is important to | explain why, or use `must` if it is a requirement |

## Nouns that hide a verb

STE rule 3.7: use the approved verb for the action.

| Do not write | Write |
| --- | --- |
| give an indication of | show |
| make an adjustment to | adjust |
| do the removal of | remove |
| carry out the installation of | install |
| is responsible for processing | processes |
| provides the ability to | lets ... |
| is in violation of | does not obey |

## Technical names and verbs used wrongly

| Do not write | Write | Rule |
| --- | --- | --- |
| Slack the team, ping the owner | send a Slack message to the team, tell the owner | STE 1.7 |
| cron the job | run the job as a cron job | STE 1.7 |
| the deploy failed | the deployment failed | STE 1.13 |
| the install | the installation | STE 1.13 |
| the ask | the request | STE 1.13 |
| brick, nuke, yeet | name the real action: `delete`, `stop` | STE 1.10 |

## Jargon we delete (house)

`happy path`, `blast radius` (in prose, but you can keep it in a heading), `low-hanging
fruit`, `move the needle`, `source of truth` (say which service owns the data),
`first-class`, `battle-tested`, `bleeding edge`, `magic`, `under the hood`,
`out of the box`, `at the end of the day`, `going forward`, `circle back`,
`deep dive`, `unpack`, `story`, `journey`.
